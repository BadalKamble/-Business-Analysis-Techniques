✨ 7 Core Techniques Explained
1. 🔍 SWOT Analysis
Strategic framework evaluating Strengths, Weaknesses, Opportunities, and Threats. Example: Banking App Project — legacy systems vs mobile-first opportunity.
2. 📋 Requirements Analysis
Discovering, documenting, and validating stakeholder needs. Key outputs: BRD, FRD, and Agile User Stories ("As a… I want… So that…").
3. 💰 Cost-Benefit Analysis (CBA)
Quantifies project viability using ROI formula: ROI = (Benefits - Costs) / Costs × 100. Decision matrix: ROI > 0% = Proceed, ROI < 0% = Revise scope.
4. 📉 Gap Analysis
Maps AS-IS (current state) to TO-BE (desired state). 4-step process: Document → Define → Identify Gaps → Prioritize Actions.
5. 🔎 Root Cause Analysis (RCA)
Digs beneath symptoms to find underlying causes. Tools: 5 Whys method and Fishbone/Ishikawa Diagram across 6 categories (Man, Machine, Method, Material, Measurement, Environment).
6. ✅ Feasibility Analysis
Evaluates project viability across 5 dimensions: Technical, Financial, Operational, Legal, and Time. Output: Feasibility Report with Go / No-Go recommendation.
7. 👥 Stakeholder Analysis
Maps stakeholders on Power-Interest Matrix into 4 quadrants: Manage Closely, Keep Satisfied, Keep Informed, Monitor Only.
